# External smart-contract audit findings

Tracks findings from external audits of the AudioBlocks contracts. Launch is blocked while any
finding rated **Critical** is open.

## Process

1. Link the audit report below when it is received.
2. Open one GitHub issue per finding and add it to the table.
3. Update the status as the finding is fixed, accepted, or disputed.
4. The security lead records sign-off before mainnet launch.
